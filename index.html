Notable projects:

GrapherToolkit

GrapherToolkit is a C++/GTKMM desktop app that evaluates and draws a graph for a given function f(x). It operates on top of a written-from-scratch library that recursively parses a string into an object model, then evaluates the function, before disaplying it through a custom GTKMM component. The library supports basic operations, as well as more complex, such as sin, cos, ln, etc.

SmartPing

SmartPing is a discord bot designed to solve discord's group pings. Roles no longer cut it when you need to create one for every new group that needs a separate pings. SmartPing organizes users into internal groups for easy management and seamless pings

MiniBeat

MiniBeat is a small osu!mania inspired rhythm game, made in C# + Raylib. It uses simple JSON files to store and load maps
