It's time for the daily minecraft session? Maybe a poll you want your friends to complete? Something else?

As you need to ping more and more people, this becomes a chore. @person1 @pesron2 [. . .] grows longer every time

You might claim that discord actually solved this issue with roles - and sure, that's a good argument to make. But roles clearly don't cut it anymore. While useful, they impose restrictions, that include, among other things:

  • A maximum number of roles allowed per discord server exists

  • The ability to add/remove roles belongs only to admins, outside of onboarding roles which have a limited amount of options

  • Moreover, users don't have the ability to create roles for themselves unless in a small privates server where giving this permission is a matter of trust

  • The "Anyone can @mention this role" setting allows the role to be spam pinged

SmartPing solves all of those issues and more by implementing a custom ping function that saves user groups in a database to retreive on demand
